# gostd Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `crates/gostd`: the Go-exact pieces of Go std 1.27.4, x/text v0.27.0, x/exp (055de637280b) and BurntSushi/toml v1.4.0 that graphify-go v0.12.0 calls, each proved equal to Go by ported Go tests and by a Go-vs-Rust `diff -r` oracle.

**Architecture:** One crate, one module per Go package, no third-party crates. Unicode tables are generated in CI from pinned UCD files by a std-only generator crate (`crates/gostd-gen`) and committed; the `test` stage regenerates them and fails on a diff. A Go oracle program (`parity/go/oracle`) and a Rust example (`crates/gostd/examples/oracle.rs`) run the same operations on the same generated inputs; the main-only `parity` stage diffs their output trees. Every module lands as two PRs: ported tests first (ignored), then the code.

**Tech Stack:** Rust 1.99.1, edition 2024, std only. BuildKit on ARC (`ci/Dockerfile`, `.github/workflows/ci.yml`). Go 1.27.4 only inside Docker stages (`golang:1.27.4-bookworm`). beads (`bd`, `BEADS_DIR=/Users/christopherdobbyn/work/dobbo-ca/graphify-rs/.beads`).

**Spec:** `docs/superpowers/specs/2026-11-12-graphify-rs-design.md`, sections 3, 4, 5, 7, 12. Master plan: `docs/superpowers/plans/2026-11-12-graphify-rs-master.md` (Global Constraints, Task 4).

## Review Focus

The five inputs most likely to break a user that no Go test pins down. Each has a test in the owning task.

1. **Invalid UTF-8 is replaced per byte, not per maximal subpart.** Go's `utf8.DecodeRune` returns `(U+FFFD, 1)` for each bad byte; Rust's `from_utf8_lossy` folds `E2 82` into one U+FFFD. JSON string encode, XML escape, `strconv.Quote`, and the regexp byte APIs must follow Go. Tests: Task 3 (`decode_rune`), Task 5 (`quote`), Task 9 (`append_string`), Task 12 (`escape_text`).
2. **x/text normalization inserts U+034F after 30 non-starters** (stream-safe format, `composition.go:10` `maxNonStarters = 30`). A label with a long run of combining marks reaches NFKD (`normLabel`) and the NFKC fixpoint loop (`idutil.go:83-90`). Test: Task 4 `stream_safe_cgj`.
3. **TOML `[[x]]` is `[]map[string]any`, not `[]any`.** graphify asserts `.([]any)` on `workspace.members` and `project.dependencies`; an array of tables must fail that assertion, an inline array of tables must pass it. Test: Task 11 `array_of_tables_is_distinct`.
4. **Regexp compile errors reach the user** (`query.go:148-149`). The error text must be Go's, byte for byte. Test: Task 6 `error_text_matches_go`.
5. **Non-UTF-8 file names** in `walk_dir`, `glob` and `eval_symlinks` must be visited, sorted by bytes, and never panic. Test: Task 15 `walk_dir_non_utf8_name`.

Each module task is two PRs. The task text gives only what differs.

- [ ] Add the module's public API from the task's **Interfaces** block with `todo!()` bodies, under `#[allow(unused_variables)]` on the module (removed in PR B), so the tests compile.
- [ ] Port the task's **Tests** list into `crates/gostd/tests/<pkg>_<gofile>.rs` (Go `regexp/find_test.go` becomes `tests/regexp_find.rs`; Go `TestFindString` becomes `fn test_find_string`). Table rows become `const` arrays with the Go values copied verbatim. Every test is `#[ignore = "<bead>"]`.

- [ ] Add the module rows to `parity/README.md`: source tests, ported, passing = 0, not ported (each with a reason: "not reached by graphify-go" names the Go function).
- [ ] `cargo fmt`, commit, push, open the PR. Expected: `test` green (tests compile and are ignored). Squash-merge.

**PR B, code** (branch `port-<area>-<4 hex>`):
- [ ] Implement the module. Remove every `#[ignore = "<bead>"]` of this bead and the `allow(unused_variables)`. Verify: `grep -rn '<bead>"' crates/gostd` prints nothing.
- [ ] Add the task's **Oracle ops** to `parity/go/oracle/<pkg>.go` and `crates/gostd/examples/oracle/<pkg>.rs`, and raise `PARITY_MIN_OUTPUTS` in `ci/Dockerfile` to the new total.

- [ ] `cargo fmt`, commit, push, PR. Expected: `test` green with the tests running (the CI log lists them as `ok`, not `ignored`). Squash-merge.
- [ ] Confirm `arm64`, `parity` and `parity-arm64` are green on main. Then `bd close <bead> && bd dolt push`, and report the PR to the coordinator.

If the oracle diff is not empty, the Rust side is wrong: fix it in a new PR; never edit the Go oracle to match.

## Decisions for the reviewer

- Shortest float digits come from Rust `{:e}`, with Go's layout ported (Task 5). Fallback if the oracle shows one difference: port `uscale.go`.
- Stable sorts are ported exactly (Task 16) although their result is unique; the call trace then matches too.
- x/text fold is generated from `CaseFolding.txt` C+F (Task 4) and checked on every code point against x/text, instead of porting x/text's trie layout.
- `RE2Exhaustive` and toml-test come from the Go toolchain image and the `go.sum`-verified BurntSushi module (`testinputs` stage); `NormalizationTest.txt` comes from the hash-locked `ucd` stage. Small Go test data files are committed under `crates/gostd/testdata/`.
- `url` and fs-touching `filepath` APIs use bytes / `Path`, because Go strings can hold invalid UTF-8 there (`%ff` hosts, file names).
