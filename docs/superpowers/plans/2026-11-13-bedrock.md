# bedrock crate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `crates/bedrock` makes graphify-go's one Bedrock call (internal/semantic/bedrock.go:103) with the same request body, auth, credential chain, retries and error text, on our own HTTP/1.1 client over rustls.

**Architecture:** Seven private modules under one small public API (`Config`, `Env`, `Client::new`, `Client::record_concepts`, `Error`). Leaf modules (sha, time, json) have no dependencies on each other except json; sigv4 uses sha and time; creds uses json, time and the ini port; http uses rustls; `client` puts them together. Every test lands first, ignored with its bead id, in Task 1; each later task removes the ignores for its part.

**Tech Stack:** Rust 1.99.1, edition 2024, std only plus `rustls` 0.23 (default-features off), `rustls-graviola` 0.4, `webpki-roots` 1. CI on BuildKit (`ci/Dockerfile`, target `ci`).

**Spec:** `docs/superpowers/specs/2026-11-12-graphify-rs-design.md` sections 2, 4 and 10; master plan `docs/superpowers/plans/2026-11-12-graphify-rs-master.md` (Global Constraints, Task 4). Oracle sources (read only): graphify-go 35fcd9e, anthropic-sdk-go v1.51.0, aws-sdk-go-v2 v1.30.3 with config v1.27.27, credentials v1.17.27, internal/ini v1.8.0, smithy-go v1.20.3, all in `~/go/pkg/mod`. ## Decisions (coordinator review of PR #4, 2026-11-13: approved)

1. **Scope split with P2: yes.** graphify-go's `parseConcepts` and `Enrich` need `idutil.MakeID`, `model`, `detect.IsSensitive` and `cache.HashBytes`. This crate stops at the raw JSON text of the `record_concepts` tool input (Go `tu.JSON.Input.Raw()`). The 13 Go tests in `internal/semantic/bedrock_test.go` (4) and `semantic_test.go` (9) are bead `graphify-rs-ihc.1` under P2.
2. **Private SHA-256 + HMAC: yes.** `src/sha.rs`, scalar, no `unsafe`, tested with FIPS 180-4 and RFC 4231. Swap bead `graphify-rs-5sz` (gostd::sha256 is gostd Task 18).
3. **D-006: yes** (written in Task 5): (a) SSO, `role_arn`/`source_profile`, `credential_source`, `web_identity_token_file`, `AWS_WEB_IDENTITY_TOKEN_FILE`, ECS and IMDS go through `aws configure export-credentials`; (b) Go loads the shared config before the chain and fails on a broken `AWS_PROFILE` profile even when env keys are set (config.go:197-219); we read the profile only when env keys are absent. When `aws` is not on `PATH` and no other source gives credentials, the error says so and names what to set (Task 5).
4. **Proxy: yes, now.** `HTTPS_PROXY`/`https_proxy` (and `HTTP_PROXY`/`http_proxy` for an `http://` base URL), `NO_PROXY`/`no_proxy`, with Go's matching rules, through an HTTP CONNECT tunnel (Task 6). Oracle: golang.org/x/net v0.55.0 `http/httpproxy/proxy.go`, which is byte-identical to the copy vendored in Go 1.27 std (uppercase name first). One narrow divergence stays, **D-007**: a proxy URL with scheme `https://` or `socks5://` is an error here (Go supports both); `http://` and bare `host:port` work.
5. **Headers: yes.** `Host`, `Content-Length`, `Content-Type: application/json`, `Accept: application/json`, `anthropic-version: 2023-06-01`, `X-Stainless-Retry-Count: <n>`, `X-Stainless-Timeout: 600`, `User-Agent: graphify-rs-bedrock/<crate version>`, plus auth (`Authorization`, `X-Amz-Date`, `X-Amz-Security-Token`). No other `X-Stainless-*`. Body byte-exact to Go, golden in `testdata/request_body.json`.
6. **No Go oracle stage here: yes.** Bead `graphify-rs-1kw` (gostd stream) adds the body case to gostd's Go oracle. `parity/README.md` gets a `## bedrock` section only; whoever lands first creates the file with a one-line header.

Not divergences (wire only, not visible to a user): HTTP/1.1 instead of Go's HTTP/2; no `Accept-Encoding: gzip`; header order; no connection reuse.

## Review Focus

- **A note body that is not valid UTF-8 after the 200 KiB cut.** Go cuts `body[:MaxNoteBytes]` by bytes and then encodes each bad byte as `\ufffd`. `record_concepts` takes `&str`, cuts by bytes into `&[u8]`, and `json::write_string` encodes `&[u8]`. Test in Task 3 (`string_invalid_utf8_one_fffd_per_byte`) and Task 7 (`note_cut_mid_rune`).
- **A base URL from `ANTHROPIC_BEDROCK_MANTLE_BASE_URL` with or without a trailing slash, or with no path.** Go adds `/` to a non-empty path, then resolves `v1/messages` (option/requestoption.go:148-152, requestconfig.go:391). Test in Task 7 (`base_url_join`).
- **A `Retry-After` longer than the 600 s attempt deadline.** Go waits on the attempt's own context, so it returns a timeout, not a late retry. Test in Task 7 (`retry_after_past_deadline_is_timeout`).
- **A profile with SSO or `role_arn` keys and also static keys or `credential_process`.** Go never uses the static keys or the process in that case (resolve_credentials.go:138-180). We route it to the CLI fallback. Test in Task 5 (`role_or_sso_profile_uses_cli`).
- **Credentials that expire during a long run** (SSO through the CLI lasts about 1 h). Go caches and refreshes on expiry before each attempt (awsauth.go:226). Test in Task 7 (`expired_creds_are_fetched_again`).
