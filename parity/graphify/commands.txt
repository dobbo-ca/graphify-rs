# Gate command list. One command per line: <n> <corpus> <args...> [< <stdin file>]
#   <n>      unique transcript number (t/<n>.stdout, .stderr, .exit)

#            keep these lines after the builds of ggo and ggo-testdata) or /hookrepo

# corpus keeps only its Markdown and JSON files, so labels must come from those; the P2 stream
# corrects them in review. A draft that fails in Go is fine (its transcript records the error),
# but every line must be a real graphify-go invocation.
